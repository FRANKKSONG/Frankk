Esther cloud setup

Five short steps and a quick test, so what you tell Esther on your phone shows up in Esther on your PC, sorted by Jev. About 15 minutes. Tick each step as you go.

0 of 6 done

1. Make the Esther bot

iPhone · Telegram
  1. Open Telegram, search @BotFather (blue tick), tap Start, send /newbot.
  2. Name: Esther. Username: anything ending in bot, e.g. esther_frankk_bot.
  3. BotFather sends a long token. Copy it into a private note. Never send it to anyone.
  4. Tap the link to your new bot and press Start.
  5. Search @userinfobot, press Start. It shows your Id (a number). Note it too.

2. Make the Supabase project

PC · supabase.com
  1. Open supabase.com/dashboard (same login as your family bot) → New project.
  2. Name Esther, region Singapore, plan Free. Let it generate the password. Click Create and wait about a minute.
  3. Left menu → SQL Editor → New query. Click , paste, press Run. It should say “Success”.

3. Add the Esther function

PC · Supabase
  1. Left menu → Edge Functions → Deploy a new function → Via Editor.
  2. Name it exactly esther.
  3. Delete the example code. Click , paste, press Deploy.
  4. Open the function’s settings and turn Verify JWT (or “Enforce JWT verification”) off → Save.
  5. Copy the function’s address from its page. It looks like https://abcd1234.supabase.co/functions/v1/esther.

4. Add four secrets

PC · Supabase

Edge Functions → Secrets → add each name with its value. Copy the names here so there are no typos.

TELEGRAM_BOT_TOKENValue: the token from BotFather (step 1).
ALLOWED_TELEGRAM_IDValue: your Id number from @userinfobot. Only you will be heard.
ESTHER_APP_KEY Value: a long random password. Here’s one made in your browser just now; copy it, paste it as the value, and keep it for step 5.
…
JEV_API_KEYValue: your key from TypeSafe. Skip it for now if you don’t have one; Esther’s own rules will sort everything.

You don’t connect Telegram yourself: Esther does it the first time you press Connect & test in step 5.

5. Connect Esther

PC · Esther
  1. In Esther: Settings → Phone & Jev.
  2. Paste the function address (step 3) and the app key (step 4) → Connect & test.
  3. You should see green dots: Esther cloud, Telegram, and Jev if you added it.
